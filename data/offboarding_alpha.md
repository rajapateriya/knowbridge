# Project: Alpha Corp  
## Process: Offboarding

### Overview
This document defines the offboarding process for Alpha Corp to ensure secure and complete removal of access.

---

### Offboarding Steps

1. **Initiate Request**
   - Raise offboarding request in ServiceNow.
   - Mention last working day.

2. **Stakeholder Notification**
   - Inform:
     - Project Manager
     - Client SPOC
     - IT Team

3. **Access Revocation**
   Remove access to:
   - Jira
   - Confluence
   - Git repositories
   - Internal tools

4. **VPN Deactivation**
   - Disable VPN credentials.

5. **Communication Cleanup**
   - Remove from Teams channels.
   - Remove from email groups.

6. **Knowledge Transfer**
   - Ensure KT sessions completed.
   - Verify documentation handover.

7. **Asset Collection**
   - Laptop
   - ID card
   - Accessories

8. **Account Deactivation**
   - Disable email account.
   - Remove directory access.

---

### Validation Checklist

- [ ] All system access revoked  
- [ ] KT completed  
- [ ] Assets returned  
- [ ] Email disabled  

---

### Important Notes

- Access must be revoked on last working day.
- No exceptions allowed.

---

### Common Issues

- Access still active → Recheck systems  
- Missing KT → escalate immediately
