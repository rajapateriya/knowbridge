# Project: Alpha Corp  
## Process: Onboarding

### Overview
This document outlines the onboarding process for new resources joining the Alpha Corp project. The goal is to ensure that the resource gets all required access, understands project workflows, and becomes productive quickly.

---

### Onboarding Steps

1. **Raise Access Request**
   - Log in to ServiceNow.
   - Select "Alpha Corp Access" category.
   - Fill in user details (name, email, role).
   - Submit request.

2. **Approval Process**
   - Approval required from:
     - Project Manager
     - Client SPOC
   - Follow up if approval is pending for more than 24 hours.

3. **Account Setup**
   - Create official email ID.
   - Configure user in internal directory.
   - Ensure mailbox is active.

4. **VPN Access**
   - Provide VPN credentials.
   - Share setup guide.
   - Verify successful login.

5. **Tool Access**
   Grant access to:
   - Jira (Alpha Board)
   - Confluence (Alpha Space)
   - Git repository
   - Internal dashboards

6. **Communication Channels**
   - Add user to Microsoft Teams:
     - Alpha General
     - Alpha Dev
   - Add to email distribution list.

7. **Onboarding Session**
   - Schedule session with Team Lead.
   - Cover:
     - Project overview
     - Architecture basics
     - Key stakeholders

8. **Documentation Sharing**
   - Share:
     - Project SOPs
     - Architecture documents
     - Credentials (securely)

---

### Validation Checklist

- [ ] All system access granted  
- [ ] VPN working  
- [ ] Tools accessible  
- [ ] User added to communication channels  
- [ ] Onboarding session completed  

---

### Important Notes

- All access must be granted within 48 hours.
- NDA must be signed before granting any access.
- Escalate delays to Project Manager.

---

### Common Issues

- VPN not working → Check firewall / credentials  
- Jira access missing → Re-trigger request  
- Email delay → Contact IT support
