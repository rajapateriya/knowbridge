# Process: Timesheet Submission

### Overview
This document explains how to fill and submit timesheets accurately.

---

### Steps

1. Log in to Timesheet Portal.
2. Select correct project code.
3. Enter daily working hours.
4. Add task descriptions.
5. Verify total hours.
6. Submit before Friday EOD.
7. Manager reviews and approves.

---

### Validation Checklist

- [ ] Correct project selected  
- [ ] Hours filled for all days  
- [ ] Comments added  
- [ ] Submitted on time  

---

### Important Notes

- Timesheets are mandatory weekly.
- Delays may impact payroll.

---

### Common Issues

- Wrong project code → correct and resubmit  
- Missing entries → update before deadline
